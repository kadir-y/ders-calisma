# Ders Çalışma Sayfaları

Sakarya Üniversitesi dersleri için hazırlanmış test ve alıştırma sayfaları. GitHub Pages ile yayınlanır: https://kadir-y.github.io/ders-calisma/

| Klasör | Ders | İçerik |
|---|---|---|
| `ag-programlama/` | BSM 451 Ağ Programlama | 6 test (354 soru), 6 kod boşluk atölyesi |
| `finansal-okuryazarlik/` | SAU 751 Finansal Okuryazarlık | Oran analizi deneme sınavı (48 soru) |

Sayfalar tek dosyalık HTML'dir, kurulum gerektirmez. Yeni ders için bir klasör açıp kök `index.html` listesine ekle.
